# RAIN product context

RAIN is a self-hosted workbench for people launching and coordinating CLI agents on their computers. Users select a local or configured SSH host, discover tools, launch sessions, send messages through groups, inspect files, and open terminals.

This is an Operate surface. Launching on the wrong machine or saving to the wrong filesystem has real consequences. Machine selection must stay visible and persist across Machines and Files. Groups own conversation routing and workflow records, never their agent processes.

The owner explicitly requests a Material-like developer tool, light and dark modes, an ASCII RAIN wordmark and matching logo, no gradients, no bluish colors, and no pills. Use familiar Material spacing and controls while honoring these shape and palette constraints. Existing React/Tauri and plain CSS remain the implementation stack.

Assumption: desktop is the primary workbench; the phone remains a usable remote control. No marketing surface or decorative imagery is needed.
